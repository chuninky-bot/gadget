ASCII ART 변환기

TEXT2ART와 IMAGE2ART를 브라우저에서 바로 생성합니다.

입력하면 자동으로 변환됩니다. 결과가 여기에 표시됩니다.

사용 가이드

ASCII ART 변환기 사용 가이드

ASCII ART 변환기는 TEXT2ART와 IMAGE2ART 두 모드를 지원해, 짧은 문구나 사진을 문자로 이루어진 아트로 즉시 바꿔줍니다.

언제 유용한가요?

README나 커밋 메시지, 커뮤니티 게시판에 넣을 문자 배너를 만들거나, 사진을 독특한 문자 이미지로 바꿔 공유하고 싶을 때 유용합니다.

사용 방법

  1. TEXT2ART 또는 IMAGE2ART 모드를 선택합니다.
  2. 문구를 입력하거나 이미지를 업로드합니다.
  3. 폭 슬라이더와 Dense, Soft, Block, Photo, Binary 같은 문자 세트로 결과물의 느낌을 조절한 뒤 복사합니다.

알아두면 좋은 점

결과는 고정폭 글꼴에서 가장 잘 정렬되므로, 코드 블록이나 터미널처럼 고정폭 글꼴을 쓰는 곳에 붙여넣을 때 모양이 가장 정확합니다.

데이터 처리 안내

IMAGE2ART로 업로드한 사진은 브라우저 안에서만 픽셀 단위로 분석되며 외부 서버로 전송되지 않으므로, 개인 사진도 그대로 변환에 사용할 수 있습니다.

자주 묻는 질문

글자와 이미지를 모두 아스키 아트로 바꿀 수 있나요?

네. TEXT2ART와 IMAGE2ART 두 모드를 지원하며, 사진을 업로드해 문자 이미지로 변환할 수도 있습니다.

결과물의 밀도나 폭을 조절할 수 있나요?

네. 폭 슬라이더와 Dense, Soft, Block, Photo, Binary 같은 문자 세트 프리셋으로 결과물의 느낌을 조절할 수 있습니다.

변환한 이미지가 서버에 업로드되나요?

아니요. 이미지 처리는 브라우저 안에서만 이루어지며 업로드한 이미지는 외부로 전송되지 않습니다.
