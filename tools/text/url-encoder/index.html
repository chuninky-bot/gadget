URL 인코딩 변환기

입력 문자가 일반문자면 URL 인코딩으로, URL 인코딩이면 일반문자로 자동 변환합니다.

결과가 여기에 표시됩니다.

사용 가이드

URL 인코딩 변환기 사용 가이드

URL 인코딩 변환기는 일반 문자열을 퍼센트 인코딩 문자열로, 또는 그 반대로 즉시 변환해주는 도구입니다.

언제 유용한가요?

쿼리 스트링에 한글이나 공백, 특수문자를 안전하게 넣어야 할 때, 또는 로그에 남은 인코딩된 URL을 원래 문자열로 되돌려 확인할 때 유용합니다.

사용 방법

  1. 인코딩할 일반 문자열이나 디코딩할 퍼센트 인코딩 문자열을 입력창에 넣습니다.
  2. 결과 영역에서 변환된 값을 확인합니다.
  3. 필요하면 공백을 +로 바꾸는 옵션을 켠 뒤 결과를 복사합니다.

알아두면 좋은 점

&, =, 공백 같은 URL 쿼리 문자열의 특수문자도 안전하게 인코딩되므로, 변환된 값은 쿼리 파라미터나 링크에 바로 사용할 수 있습니다.

데이터 처리 안내

인코딩과 디코딩 모두 브라우저 안에서 즉시 처리되며 입력값은 서버로 전송되지 않으므로, 실제 서비스에 쓰이는 URL도 안심하고 확인할 수 있습니다.

자주 묻는 질문

인코딩과 디코딩을 모두 지원하나요?

네. 일반 문자열을 퍼센트 인코딩으로 바꾸거나, 반대로 인코딩된 문자열을 원래 텍스트로 되돌릴 수 있습니다.

쿼리 스트링의 특수문자도 처리되나요?

네. &, =, 공백 같은 URL 쿼리 문자열의 특수문자를 안전하게 인코딩합니다.

결과가 브라우저 주소창에 바로 사용 가능한가요?

네. 변환된 문자열은 URL 쿼리 파라미터나 링크에 바로 사용할 수 있는 형태로 제공됩니다.
