사용 가이드

DIFF 도구 사용 가이드

DIFF 도구는 Text, JSON, XML 세 가지 모드로 두 값을 나란히 놓고 줄 단위로 비교해 변경점을 표시합니다.

언제 유용한가요?

설정 파일의 두 버전이 뭐가 다른지 확인하거나, API 응답이 배포 전후로 어떻게 바뀌었는지 비교할 때 유용합니다.

사용 방법

  1. Text, JSON, XML 중 비교할 형식의 모드 버튼을 누릅니다.
  2. 좌우 입력창에 비교할 두 값을 각각 붙여넣고 "비교하기"를 누릅니다.
  3. "좌우 바꾸기"로 방향을 바꾸거나 "지우기"로 새로 비교를 시작할 수 있습니다.

알아두면 좋은 점

JSON, XML 모드는 형식에 맞춰 구조를 인식해 비교하므로, 단순히 줄 순서만 바뀐 경우와 실제 값이 달라진 경우를 구분해 보는 데 도움이 됩니다.

데이터 처리 안내

비교는 브라우저 안에서 즉시 처리되며 두 입력값 모두 서버로 전송되지 않으므로, 아직 배포하지 않은 설정값이나 코드도 안심하고 비교할 수 있습니다.

자주 묻는 질문

텍스트 외에 JSON이나 XML도 비교할 수 있나요?

네. 상단의 Text, JSON, XML 모드 버튼으로 전환해 각 형식에 맞는 방식으로 두 값의 차이를 비교할 수 있습니다.

좌우 입력값을 바꿔서 비교할 수 있나요?

네. "좌우 바꾸기" 버튼으로 두 입력 값의 위치를 즉시 교체해 반대 방향의 변경점도 확인할 수 있습니다.

비교한 내용이 서버에 남나요?

아니요. 비교는 브라우저 안에서 즉시 처리되며 두 입력값 모두 서버로 전송되지 않습니다.
