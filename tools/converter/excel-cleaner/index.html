Excel CSV 정리 도구

Excel에 붙여넣기 좋은 CSV/TSV 데이터를 정리하고 깨진 따옴표와 행 길이를 보정합니다.

사용 가이드

Excel CSV 정리 도구 사용 가이드

Excel CSV 정리 도구는 구분자를 자동 감지하거나 직접 선택해 CSV/TSV 데이터를 표 형태로 정리하고, 깨진 따옴표와 맞지 않는 행 길이를 보정합니다.

언제 유용한가요?

이메일이나 메모에서 복사한 표 데이터를 엑셀이나 구글 시트에 붙여넣기 전에 열 구분이 깨지지 않았는지 미리 정리하고 확인할 때 유용합니다.

사용 방법

  1. 구분자를 자동 감지로 두거나 쉼표, 탭, 세미콜론 중 하나를 직접 선택합니다.
  2. 입력창에 CSV/TSV 데이터를 붙여넣습니다.
  3. 표 미리보기로 열이 올바르게 나뉘었는지 확인한 뒤 결과를 복사합니다.

알아두면 좋은 점

닫히지 않은 따옴표나 줄 길이가 맞지 않는 행을 가능한 범위에서 보정하지만, 원본 데이터가 심하게 깨진 경우 미리보기에서 열 순서를 한 번 더 확인하는 것이 좋습니다.

데이터 처리 안내

정리된 결과는 선택한 구분자에 맞춰 제공되므로 엑셀이나 구글 시트에 바로 붙여넣기 좋으며, 입력 데이터는 브라우저 밖으로 전송되지 않습니다.

자주 묻는 질문

구분자를 직접 지정할 수 있나요?

네. 자동 감지 외에도 쉼표, 탭, 세미콜론 구분자를 직접 선택할 수 있습니다.

따옴표가 깨진 CSV도 정리되나요?

닫히지 않은 따옴표나 줄 길이가 맞지 않는 행을 가능한 범위에서 보정하고, 정리된 결과를 표 미리보기로 함께 보여줍니다.

결과를 엑셀에 바로 붙여넣을 수 있나요?

네. 정리된 결과는 선택한 구분자에 맞춰 제공되므로 엑셀이나 구글 시트에 바로 붙여넣기 좋은 형태입니다.
