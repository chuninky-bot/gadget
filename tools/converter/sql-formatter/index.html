SQL 포맷터

SQL을 읽기 좋게 정리하고 누락된 따옴표, 괄호, 세미콜론을 가능한 범위에서 자동 복구합니다.

사용 가이드

SQL 포맷터 사용 가이드

SQL 포맷터는 한 줄로 붙어 있는 SQL 쿼리를 키워드 대문자화와 줄바꿈 정리로 읽기 좋게 만들고, 끝에 세미콜론이 없으면 자동으로 채워 넣습니다.

언제 유용한가요?

로그나 ORM이 출력한 압축된 쿼리를 리뷰용으로 정리하거나, 문서·이슈에 붙여넣기 좋은 형태로 다듬을 때 유용합니다.

사용 방법

  1. 입력창에 SQL 쿼리를 붙여넣습니다.
  2. 키워드가 대문자로, 줄바꿈이 정리된 결과를 확인합니다.
  3. 정리된 쿼리를 복사해 문서나 코드 리뷰에 사용합니다.

알아두면 좋은 점

특정 데이터베이스 전용 문법보다는 SELECT, INSERT, UPDATE 같은 공통적인 SQL 구조를 보기 좋게 정리하는 데 초점을 맞췄습니다.

데이터 처리 안내

정리는 브라우저 안에서만 이루어지므로 실제 테이블명, 컬럼명, 조건값이 포함된 쿼리도 서버로 전송하지 않고 확인할 수 있습니다.

자주 묻는 질문

세미콜론이 없는 쿼리도 정리되나요?

네. 문장 끝에 세미콜론이 없으면 자동으로 추가해 정리합니다.

특정 DB(MySQL, PostgreSQL 등) 문법에 맞춰 최적화되어 있나요?

특정 DB 전용 문법보다는 SELECT, INSERT, UPDATE 같은 공통적인 SQL 구조를 정리하는 데 초점을 맞췄습니다.

실제 테이블명이 포함된 쿼리를 넣어도 안전한가요?

네. 모든 정리는 브라우저 안에서만 처리되며 입력한 쿼리는 서버로 전송되지 않습니다.
