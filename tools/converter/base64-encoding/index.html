Base64 인코딩 변환기

하나의 입력값을 대중적인 문자 인코딩별 Base64 결과로 펼쳐 봅니다.

결과가 여기에 표시됩니다.

사용 가이드

Base64 인코딩 변환기 사용 가이드

Base64 인코딩 변환기는 입력한 텍스트를 UTF-8, EUC-KR, Shift_JIS를 포함한 10가지 문자 인코딩 기준의 Base64 값으로 동시에 변환하고, 반대로 Base64 값을 여러 인코딩으로 디코딩할 수도 있습니다.

언제 유용한가요?

인증 토큰, 이미지 데이터 URI, 오래된 시스템에서 온 Base64 값처럼 인코딩이 명확하지 않은 데이터를 다룰 때 여러 인코딩 결과를 한 번에 비교할 수 있어 유용합니다.

사용 방법

  1. 일반 텍스트를 입력해 인코딩하거나, Base64 문자열을 입력해 디코딩합니다.
  2. UTF-8, EUC-KR, Shift_JIS 등 인코딩별 결과를 나란히 확인합니다.
  3. 필요한 인코딩의 결과를 복사해 사용합니다.

알아두면 좋은 점

디코딩 결과 중에서 실제로 읽히는 문장이 있는 인코딩을 원본으로 판단하면 되며, 지원하지 않는 인코딩으로 만들어진 값은 모든 후보가 깨져 보일 수 있습니다.

데이터 처리 안내

인코딩과 디코딩 모두 브라우저 안에서 처리되므로, 토큰이나 개인 정보가 포함된 값이라도 서버로 전송하지 않고 확인할 수 있습니다.

자주 묻는 질문

여러 문자 인코딩을 동시에 확인할 수 있나요?

네. 입력값을 UTF-8, EUC-KR, Shift_JIS 등 10가지 문자 인코딩 기준의 Base64 결과로 한 번에 변환해 보여줍니다.

디코딩도 가능한가요?

네. Base64 문자열을 입력하면 지원하는 여러 인코딩으로 되돌린 결과를 함께 보여주므로, 그중 원본과 일치하는 결과를 고르면 됩니다.

EUC-KR이나 Shift_JIS처럼 오래된 인코딩도 지원하나요?

네. UTF-8, EUC-KR, UTF-16LE, ISO-8859-1, Windows-1252, Shift_JIS, GBK, Big5, EUC-JP, Windows-1251까지 총 10가지 인코딩을 지원합니다.
