사용 가이드

이미지 픽셀화 필터 사용 가이드

이미지 픽셀화 필터는 업로드한 사진을 블록 크기 슬라이더로 조절해 레트로 8비트 게임 스타일의 픽셀 아트로 즉시 바꿔주는 도구입니다.

언제 유용한가요?

프로필 사진이나 이미지를 레트로 게임풍으로 꾸미고 싶을 때, 또는 인디 게임 자료나 아이콘용으로 픽셀 아트 느낌의 이미지가 필요할 때 유용합니다.

사용 방법

  1. 이미지 파일을 업로드합니다.
  2. 블록 크기 슬라이더로 픽셀 크기를 조절하며 결과를 실시간으로 확인합니다.
  3. 원하는 픽셀 강도가 나오면 브라우저의 이미지 저장 또는 우클릭 저장으로 결과물을 내려받습니다.

알아두면 좋은 점

블록 크기를 크게 할수록 픽셀 하나하나가 커져 더 거친 레트로 느낌이 나고, 작게 할수록 원본에 가까운 부드러운 결과가 됩니다.

데이터 처리 안내

이미지 처리는 브라우저의 캔버스 기능만으로 이루어지며, 업로드한 사진은 외부 서버로 전송되지 않습니다.

자주 묻는 질문

결과 이미지를 다운로드하는 버튼이 있나요?

별도의 다운로드 버튼 대신 브라우저의 이미지 저장 기능이나 결과 화면을 우클릭해 이미지로 저장하는 방식을 사용합니다.

블록 크기는 어느 범위까지 조절할 수 있나요?

가장 세밀한 4부터 가장 거친 48까지 슬라이더로 조절할 수 있어, 은은한 효과부터 확실한 레트로 느낌까지 다양하게 만들 수 있습니다.
