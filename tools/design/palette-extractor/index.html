사용 가이드

이미지 주요 색상 추출기 사용 가이드

이미지 주요 색상 추출기는 업로드한 이미지에서 가장 많이 쓰인 색상 5가지를 자동으로 골라 HEX 코드로 보여주는 도구입니다.

언제 유용한가요?

로고나 사진에 어울리는 배색을 디자인에 쓰고 싶을 때, 이미지의 대표 색상을 눈으로 찾는 대신 빠르게 추출하고 싶을 때 유용합니다.

사용 방법

  1. 이미지 파일을 업로드합니다.
  2. 자동으로 추출된 5가지 색상 스와치를 확인합니다.
  3. 원하는 색상 스와치를 클릭해 HEX 코드를 바로 복사합니다.

알아두면 좋은 점

색상은 이미지를 작게 줄인 뒤 픽셀을 표본 추출해 계산하므로, 아주 미세한 색조 차이보다는 이미지 전체에서 눈에 띄게 많이 쓰인 색 위주로 뽑힙니다.

데이터 처리 안내

업로드한 이미지는 브라우저 안에서만 분석되며 외부 서버로 전송되지 않으므로, 공개하지 않은 사진도 안심하고 사용할 수 있습니다.

자주 묻는 질문

정확히 몇 가지 색상을 추출하나요?

가장 많이 쓰인 색상 5가지를 추출해 스와치로 보여줍니다.

색상 스와치를 클릭하면 무슨 일이 일어나나요?

클릭한 색상의 HEX 코드가 클립보드에 바로 복사되어, 별도 선택 없이 곧바로 디자인 도구나 코드에 붙여넣을 수 있습니다.
