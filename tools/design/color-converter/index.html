Color Code Converter

Convert HEX colors into RGB and HSL.

사용 가이드

색상 코드 변환기 사용 가이드

색상 코드 변환기는 HEX 색상 코드 하나를 입력하면 RGB와 HSL 값으로 동시에 변환하고 색상 미리보기까지 보여주는 도구입니다.

언제 유용한가요?

디자인 도구에서 HEX 값만 알고 있는데 CSS에서 hsl()로 채도나 밝기를 조절하고 싶을 때, 또는 반대로 RGB 기준 코드가 필요할 때 유용합니다.

사용 방법

  1. HEX 색상 코드를 입력창에 붙여넣거나 직접 입력합니다.
  2. 색상 미리보기가 입력한 색으로 바뀌는지 확인합니다.
  3. 결과에 표시된 HEX, RGB, HSL 값 중 필요한 형식을 복사합니다.

알아두면 좋은 점

3자리 축약 HEX 코드(예: #0f0)도 인식해 6자리로 확장한 뒤 변환하므로, 축약형과 전체 자릿수 코드를 구분하지 않고 입력해도 됩니다.

데이터 처리 안내

변환은 브라우저 안에서 즉시 이루어지며 입력한 색상 값은 서버로 전송되지 않습니다.

자주 묻는 질문

3자리로 줄인 HEX 코드도 입력할 수 있나요?

네, #0f0처럼 3자리로 줄인 코드도 자동으로 6자리로 확장해 변환합니다.

RGBA나 HSLA처럼 투명도가 있는 값도 지원하나요?

아니요, 현재는 불투명한 HEX, RGB, HSL 값만 변환합니다. 투명도가 필요하면 변환된 RGB나 HSL 값 뒤에 알파 값을 직접 추가해 RGBA나 HSLA 형태로 만들면 됩니다.
