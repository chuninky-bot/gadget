가이드

도구를 쓰기 전에 알아두면 좋은 개념을 짧게 정리했습니다.

가이드는 도구를 쓰기 전에 알아두면 좋은 개념을 짧게 정리한 글 모음입니다. 도구 사용법이 아니라 JSON, 인코딩, SQL, CSV, UUID가 실제로 무엇이고 왜 중요한지를 설명합니다.

JSON이란 무엇인가 JSON의 기본 구조와 자주 발생하는 문법 오류를 정리합니다. UTF-8과 EUC-KR, 한글이 깨지는 이유 문자 인코딩이 무엇인지, 한글이 깨져 보이는 원인을 설명합니다. SQL을 보기 좋게 정리해야 하는 이유 압축된 SQL 쿼리가 읽기 어려운 이유와 정리 방법을 설명합니다. CSV·TSV와 엑셀 호환 데이터 정리하기 CSV와 TSV의 차이와 데이터가 깨지는 이유를 설명합니다. UUID란 무엇이고 왜 필요한가 UUID가 무엇인지, 자동 증가 ID 대신 쓰는 이유를 설명합니다.
